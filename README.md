# PulsePress — современный новостной сайт на Django

Полноценный новостной портал с backend на **Python Django** и frontend на **HTML/CSS/JS**.

## Реализованные современные функции
- Главная страница с hero-блоком, трендами и featured-новостями.
- Полноценная лента новостей с поиском, фильтрацией по категориям и тегам.
- Детальная страница статьи с увеличением счётчика просмотров.
- Система комментариев (только для авторизованных пользователей).
- Система лайков с AJAX-обновлением без перезагрузки.
- Авторизация пользователей (Django auth).
- Подписка на рассылку (валидируемая форма).
- Адаптивный современный дизайн в тёмной стилистике.
- Готовая админка для управления контентом.

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Открыть сайт: `http://127.0.0.1:8000/`

## Структура
- `news_portal/` — конфигурация Django-проекта.
- `news/` — приложение с моделями, вьюхами, маршрутизацией.
- `templates/` — HTML-шаблоны.
- `static/` — стили и JS.
